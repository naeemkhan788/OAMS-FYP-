# Quick MongoDB Compass Connection

## 🎯 **Connect Compass to Your Project**

### **Step 1: Open MongoDB Compass**
- Launch MongoDB Compass from your desktop/start menu

### **Step 2: Create New Connection**
- Click **"New Connection"** button

### **Step 3: Enter Connection Details**
- **Connection String:** `mongodb://localhost:27017/oams`
- **Name:** `OAMS Project`

### **Step 4: Connect**
- Click **"Connect"** button

## 🚨 **If Connection Fails**

MongoDB is not installed locally. You need to:

### **Option 1: Quick Fix - Use Atlas**
1. Go to: https://www.mongodb.com/cloud/atlas
2. Create free account (2 minutes)
3. Create cluster (M0 Sandbox)
4. Get connection string
5. Update .env file with Atlas connection

### **Option 2: Install MongoDB**
1. Download: https://www.mongodb.com/try/download/community
2. Install MongoDB Community Server
3. Start MongoDB service
